# Consultas de Inteligencia Artificial (Evidencia Criterio 2.1.4)

A continuación, se detallan los prompts (consultas) utilizados para generar el código de las validaciones de los formularios y el carrusel de imágenes, de acuerdo con la rúbrica de evaluación.

## 1. Prompt para el Carrusel de Imágenes
**Consulta realizada:**
"Necesito crear un carrusel de imágenes dinámico en JavaScript para una landing page. El carrusel debe modificar el DOM cambiando la clase 'active' de las imágenes. Debe tener tres imágenes representativas del estudio musical, y botones de 'Anterior' y 'Siguiente'. La lógica debe permitir volver a la primera imagen al pasar la última y viceversa. Por favor, provee el HTML semántico dentro de un section, el CSS para ocultar/mostrar (display: none/block con animación) y la lógica JS."

## 2. Prompt para Formularios y Validaciones (Criterio 2.1.2 y 2.1.3)
**Consulta realizada:**
"Necesito integrar 3 formularios en mi página (Inscripción, Login y Contacto) asegurando que cada <label> esté vinculado a su <input> con 'for' y 'id'. Para la validación en JS:
1. Usa preventDefault().
2. Valida que no haya campos vacíos y que los formatos de email sean correctos usando una expresión regular (buenas prácticas de seguridad).
3. Organiza el código en funciones modulares (ej: validarDatos(), actualizarDOM() para feedback de errores).
4. Para la lógica de datos, utiliza un arreglo 'usuariosRegistrados' y crea objetos literales con la información del usuario al registrarse (Inscripción).
5. En el Login, verifica si el usuario y contraseña coinciden con algún objeto en el arreglo."

## 3. Prompts de Optimización y Buenas Prácticas
**Consulta realizada:**
"Revisa este código JavaScript de validación de formularios y sugiere mejoras de seguridad y estructura. Asegúrate de que los mensajes de error se muestren claramente en el DOM sin usar 'alert()' y que el código sea fácil de mantener."
